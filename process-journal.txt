2026-11-05 3:30-5:30

Completed parseHeader method that separates the header into ASCII values and frequency counts.Used a loop to
read each pair and store the count at the matching index in a frequency array. An empty header returns an array of zeros.

Completed huffmanDecode method that reads the header and uses parseHeader and createHuffTree to rebuild the Huffman tree.
The method follows the encoded bits, moving left for 0 and right for 1. Each time it reaches a leaf, it writes that
character to the output file and starts again at the root. Also handled empty files and single-character files,
where the character and number of repetitions come entirely from the header.
